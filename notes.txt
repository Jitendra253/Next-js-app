->Server side scripting vs client side scripting
    ->Client-side scripting executes in the user's browser and is mainly responsible for UI and user interactions. Server-side scripting executes on the server and handles business logic, authentication, API processing, and database operations. React is primarily client-side, while Node.js is server-side.

    -Next.js supports both server and client execution. By default, components in the App Router are Server Components, which execute on the server. When we add 'use client', the component becomes a Client Component and can use browser APIs and interactive React features such as useState and event handlers. SSR refers specifically to rendering HTML on the server, while Server Components refer to where the React component code executes.

*Questions:

->What is the pattern for creating page in next.js
    ->In modern Next.js with the App Router, pages follow a file-system-based routing pattern.
    ->Next.js App Router uses file-system-based routing. The app directory contains route segments, and a page.js file defines the UI for a route. Folders create URL segments, while square brackets such as [id] are used for dynamic routes.
->Do we need to install any package for routing in next.js

->Next.js uses a file-system based router.

    ->"In Next.js, linking means creating navigation between routes using the Link component from next/link. It enables client-side navigation without a full page reload. For navigation triggered programmatically, such as after login or form submission, we can use useRouter from next/navigation."

    ->Link = User navigation
    ->useNavigate = Code navigation
->Different between Link and Navigation.
    ->Link is used for declarative navigation where the user interacts with a link, while useNavigate is used for programmatic navigation where navigation is triggered by JavaScript logic.

->How common jayout works in Next.js
    ->A common layout in Next.js is created using layout.js. It contains shared UI such as Navbar, Sidebar, and Footer. The current page is rendered inside the layout through the children prop. Next.js supports both root layouts and nested layouts, allowing different sections of an application to have their own common UI.
